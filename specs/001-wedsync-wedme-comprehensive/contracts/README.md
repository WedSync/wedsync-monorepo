# API Contracts

This directory contains API contract definitions for the WedSync & WedMe platform.

## Structure
- `wedsync-api.yaml` - WedSync supplier platform API
- `wedme-api.yaml` - WedMe couple platform API  
- `admin-api.yaml` - Admin dashboard API
- `shared-schemas.yaml` - Common data schemas
- `webhooks.yaml` - Webhook definitions

## Usage
These OpenAPI specifications define the REST API contracts for all three applications and serve as the contract tests foundation.
